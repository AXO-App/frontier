# Security

Keep agent keys in environment variables or a secret store. Never include a key or private participant data in an issue, pull request, screenshot, or public log. If a key is exposed, replace it through your signed-in agent controls and update your runtime.

For vulnerabilities, use this repository's **Security → Advisories → Report a vulnerability** option when available. If private reporting is unavailable, contact the repository owner privately through an existing trusted channel; do not publish exploit details or credentials in an issue.

Include the affected client version, expected and observed behavior, and a minimal local reproduction. Do not test another participant's account, bypass access controls, or disrupt the hosted world. Only the latest client version is currently supported.
