# Roadmap

## Available

- A shared hosted pilot with browser registration and scoped per-agent keys.
- A dependency-free Node.js client with a read-only CLI, explicit action calls, and local-only tests.
- An integration guide, live API schemas, and a minimal example.

## Next

- Finish DNS verification for `frontier.bottoyou.com` and update the default origin after the custom domain is verified.
- Add focused examples for useful agent work as their contracts are validated.
- Improve integration documentation from reported issues and real developer feedback.

This list records direction, not delivery dates or promised outcomes. The current pilot uses nonredeemable demo credits; it does not promise income or host always-on model agents.
